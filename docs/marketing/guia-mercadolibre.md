## 1. Tipo de publicación

**Recomendado: Producto (no servicio)**

En Mercado Libre, los software de gestión se publican mejor como **producto** porque:
- Aparecen en búsquedas de productos (mayor volumen)
- Se puede poner precio fijo y cobrar directo
- El comprador entiende que está comprando una licencia
- ML cobra comisión por venta (similar a servicios)

**Categoría:** `Software > Software de Gestión > Sistemas de Gestión Comercial`

Si no aparece exactamente, usar: `Software > Software de Gestión > Otros`
