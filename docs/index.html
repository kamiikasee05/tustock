Preguntas frecuentes

¿Realmente funciona sin internet?
Sí. El sistema funciona 100% local en tu PC. Solo necesitás internet si querés usar el Monitor Cloud para ver tus datos desde el celular.
¿Puedo probarlo antes de comprar?
Sí. El plan Trial es gratis por 30 días. Podés cargar hasta 100 productos y usar todas las funciones básicas.
¿Qué pasa si cambio de PC?
Reinstalás TUSTOCK, ponés tu misma clave de licencia y listo. Tus datos los podés respaldar y restaurar con un clic.
¿Cómo funciona el Monitor Cloud?
Es una página web con URL fija. Entrás desde el celular, ponés tu usuario y ves las ventas del día, stock bajo y deudores. Los datos se actualizan cada 30 segundos.
¿Dan factura?
Sí, factura C. TUSTOCK está orientado a gestión interna, pero cumplimos con la obligación de facturar.
